# EDUPREP Digital Waveform Viewer – Training Edition

Welcome to the **EDUPREP Digital Waveform Viewer – Introductory Training Package**.

The EDUPREP Digital Waveform Viewer is a digital signal analysis tool designed to assist with the examination, measurement and interpretation of digital circuit simulation waveforms. It enables candidates to investigate digital circuit behaviour, identify signal transitions and analyse timing relationships between signals.

### Download the Application

Download the latest version of the EDUPREP Digital Waveform Viewer from the Releases section.

### Package Contents

This introductory package includes:

- **EDUPREP Digital Waveform Viewer** application.
- **Sample Simulation Data** (VCD files) for analysis.
- **Candidate Assessment Brief** containing the training and assessment instructions.

### Training Exercise

The demonstration exercise introduces candidates to:

- Digital waveform analysis and interpretation.
- Logic state identification (HIGH and LOW).
- Signal transition analysis.
- Multi-bit bus interpretation.
- Timing measurements and clock-cycle analysis.
- Identification of abnormal digital circuit behaviour.

### Getting Started

1. Download and extract the repository.
2. Open the `Software` folder.
3. Run `EDUPREP_Digital_Waveform_Viewer.exe`.
4. Load the supplied reference simulation data from the `Sample_Data` folder.
5. Follow the instructions in the Candidate Assessment Brief.
6. Use the circuit schematic provided in the assessment brief as a reference.
